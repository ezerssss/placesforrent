# Placesforrent

Platform to find places for rent including University dorms in Miagao.

🏷️ **Status:** Archived \
🤖 **Vibe Coded:** No

---

## What it does

- Browse for listed properties.
- Search for specific names, places, description, and other attributes.
- Rate and comment on listed properties.
